# Visual contract (2026-10-21)

Reference: `concept_project_page.png` (Codex image_gen, one concept, light path). The concept guides composition only; every map, number and chart on the site is drawn from the real data.

Preserve
- First screen of the project page: a large real county map is the visual anchor (about two thirds of the width); a narrow left column holds the title, one sentence and one button.
- Off-white page, white state lines over the county fill, no cards, no gradients, one sans typeface.
- Blue-grey-red diverging palette for observed minus expected (blue lower, red higher, warm grey midpoint); compact legend under the map.
- A dot plot is the next visual after the hero.

Allowed variation
- Top navigation bar; dark mode from the same tokens; section order below the first chart.

Targets
- Desktop 1440 x 900 and 1280 x 800; phone 390 x 844 (single column, map below the text).

Done when
- Hero fits one viewport on desktop, map renders real data, no em dashes, no widows in headings, both themes checked, numbers match `site/data/findings.js`.
