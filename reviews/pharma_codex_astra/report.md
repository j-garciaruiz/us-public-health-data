## Ranked findings and fixes

1. **High: NHANES cannot identify drugs in this cycle.** Replace its description with use/count only; choose a documented earlier cycle for molecule-level analyses.
2. **High: ASP already incorporates most rebates.** Remove the blanket “none subtracts rebates”; distinguish each price measure and dataset, including ASP payment exceptions.
3. **High: MFP effectuation is not exclusively an MTF refund.** Describe prospective and retrospective options and optional payment routing; do not infer realized MFP from NADAC.
4. **High: Part B plus Part D files are not total Medicare drug spending.** State traditional-Medicare Part B coverage, missing MA medical-benefit drugs and Part A inpatient drugs.
5. **High: quarterly Part D lacks unit quantities/prices.** Correct the schema description and stop any proposed unit-price calculation based on that file.
6. **Medium: suppression explanation omits secondary suppression.** Retain the verified count, document each file's rules, preserve missing values and qualify small-state comparisons.
7. **Medium: FUL is not always 175% of weighted AMP.** Include the NADAC acquisition-cost floor and aggregate-limit scope.
8. **Medium: effective-date logic bridges missing weeks.** Join adjacent snapshots by NDC; retain the ten unchanged refresh flags but correct the underlying shares.
9. **Medium: early-year single-snapshot crash.** Guard `weeks.index[-2]` and omit unavailable transitions; retain valid current-snapshot output.
10. **Medium: source grain/selection is misdescribed.** Label First Time NADAC as rate groups and Vermont as a selected insurer-list subset; do not treat either as a complete product universe.
11. **Medium: release metadata is confused with coverage/cadence.** Apply the FAERS, AMP, Drugs@FDA, VA and NPPES corrections in the table; separate SPUF contract years and resolve recall-history coverage before trend work.
12. **Medium: important access and validity information is missing.** Add Orange Book API and CBP bulk links; add FAERS noncausality/duplicate-report caveats, NDC-not-approval, NPI-not-operating-pharmacy, ARCOS buprenorphine gaps and explicit price-unit conversions.
13. **Medium: interpretive language exceeds the evidence.** Bound Januvia/Xarelto's flat period; call the IRA project an acquisition-price study. Remove “nobody pays AWP” and unsupported claims that FFS changes are mostly program design. Pre/post price changes do not identify a policy effect.
14. **Medium: access claims overstate verification.** Change Program Statistics to bulk; use conditional access language for GoodRx/Cost Plus and mark blocked/unavailable sources honestly. Do not call an untested browser route confirmed.
15. **Low: provenance count and summary precision.** Correct 2025 to 1,608,416, count CSV records, preserve median 30,168.5, and clarify increase denominators.
